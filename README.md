# Student OS 🚀
> A modular, Python-based local operating system designed to manage student life, finances, academics, and career growth in South Africa.

## 🧠 Core Pillars
* **Financial Lifeboat**: Tracks allowances, fixed costs, daily safe-to-spend limits, and splits P2P ride-pool fares.
* **Academic Hub**: Manages registered modules, lecture schedules, and countdowns for assignment deadlines.
* **Mental & Focus Engine**: Pomodoro-style study tracker equipped with XP leveling, streak gamification, and session logging.
* **Career Pipeline**: A proof-of-work ledger tracking real GitHub repositories, tech stacks, and deployment statuses.

## 🛠️ Tech Stack
* **Language**: Python 3
* **State Management**: Local JSON persistent storage architecture
* **Architecture**: Clean multi-file modular design with a centralized `main.py` controller
